# AED SYNTAX HIGHLIGHTING
* aed-pseudocodigo (v0.0.1)
* Resaltado de sintaxis para el pseudocódigo de Algoritmos y Estructuras de Datos (UTN FRRe).

## 🧠 USO

Para que el resaltado se aplique correctamente, debes utilizar archivos con extensión ".aed" y no ".txt" como normalmente usamos para escribir pseudocódigo.

Una vez creado nuestro archivo ".aed", la extensión empezará a mostrarte las palabras clave de la sintaxis de pseudocódigo en colores, haciendo más legible el código y menos plano.
